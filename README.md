# Image Upload & Display App

A C# application for uploading and displaying images with a user-friendly interface.

## Overview

This project is an image management application built with C#, designed to provide an intuitive way to upload, store, and display images. The application offers a straightforward interface for users to manage their image collections.

## Features

- **Image Upload**: Upload images from your local system
- **Image Display**: View uploaded images in an organized interface
- **File Management**: Manage image files efficiently
- **User-Friendly Interface**: Simple and intuitive UI for easy navigation

## Technology Stack

- **Language**: C#
- **Platform**: .NET Framework / .NET Core

## Getting Started

### Prerequisites

- .NET Framework or .NET Core installed on your system
- Visual Studio or Visual Studio Code
- Windows operating system (if using .NET Framework)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/liewvk/ImageUploadDisplayApp.git
   cd ImageUploadDisplayApp
   ```

2. Open the project in Visual Studio:
   ```bash
   ImageUploadDisplayApp.sln
   ```

3. Restore NuGet packages:
   ```bash
   dotnet restore
   ```

4. Build the project:
   ```bash
   dotnet build
   ```

5. Run the application:
   ```bash
   dotnet run
   ```

## Usage

1. Launch the application
2. Click the **Upload** button to select images from your computer
3. View your uploaded images in the display area
4. Manage your image collection using the provided options
